## ✨ Fitur Utama

- 📱 **Progressive Web App (PWA)**: Pasang aplikasi ini ke *homescreen* HP Anda seperti aplikasi bawaan (native) untuk akses super cepat.
- 🔗 **Habit Stacking**: Gabungkan beberapa rutinitas menjadi satu alur berurutan yang mudah dikelola berdasarkan prinsip *Atomic Habits*.
- 📊 **Statistik & Peta Panas**: Visualisasikan konsistensi Anda melalui grafik kontribusi harian dan kalender matriks yang interaktif.
- 🌓 **Tema Dinamis & Blue Light Filter**: Mata tetap nyaman di malam hari dengan filter cahaya otomatis dan dukungan Mode Gelap/Terang.
- 🧘‍♂️ **Timer Fokus Bawaan**: Kerjakan kebiasaan tipe durasi dengan *brown noise ambient audio* yang berjalan lancar di latar belakang.
- 🔒 **Privasi Terjamin (Offline-First)**: Data Anda 100% tersimpan di peramban (*local storage*) tanpa sinkronisasi ke server luar. Aman dan cepat.
- 💡 **Mood Tracker Harian**: Lacak suasana hati setiap hari untuk melihat korelasi antara penyelesaian kebiasaan dengan kebahagiaan Anda.

## 🚀 Instalasi & Menjalankan Lokal

Pastikan Anda memiliki [Node.js](https://nodejs.org/) yang telah terinstal.

1. **Clone repository ini**
   ```bash
   git clone https://github.com/yufisafangat50-star/Pelacak-Kebiasaan.git
   cd Pelacak-Kebiasaan
   ```

2. **Instal dependensi paket**
   ```bash
   npm install
   ```

3. **Jalankan server pengembangan (Dev Server)**
   ```bash
   npm run dev
   ```

4. **Buka di Browser**
   Buka URL lokal yang tertera pada terminal Anda (misal: `http://localhost:5173`).
